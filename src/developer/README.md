# Режим разработчика

`Ctrl+D` (в том числе в русской раскладке) открывает экран из меню, сюжета,
мини-игр и меню паузы. Текущие сцены приостанавливаются. `Ctrl+D`, `Esc`
или «Вернуться в игру» возвращают к прежнему состоянию, сохраняя уже
существовавшую игровую паузу.

Кнопка запускает выбранную мини-игру заново, останавливая прежние сцены.
После прохождения продолжается соответствующая сюжетная сцена.
Выбор меняет сохранённую позицию прохождения, как обычный переход в игре.

Кнопка «Сбросить сохранение» удаляет прогресс, историю реплик и результаты
мини-игр, останавливает текущие сцены и возвращает в главное меню.
После этого «Начать» запускает сюжет с первого экрана. Сброс действует
сразу, без подтверждения; настройки громкости сохраняются.

## Подключение и удаление

Модуль подключается только из корневого `main.js` через условный динамический
импорт. Игровые сцены не зависят от него. Экран — модальный HTML-слой над
Phaser: клавиатура и мышь не попадают в приостановленную игру.

- По умолчанию режим включён и в `npm run dev`, и в `npm run build`.
- Чтобы исключить его из сборки, задайте `VITE_DEVELOPER_MODE=false`
  в `.env.local` (или `.env.production.local` только для сборки) и перезапустите
  Vite / выполните `npm run build`. Vite удалит динамический импорт, JS и CSS
  модуля. Пример настройки находится в `.env.example`.
- Чтобы удалить исходники, удалите условный блок подключения в `main.js`
  и папку `src/developer`. Больше править игровые сцены не нужно.
- `installDeveloperMode` возвращает функцию отключения: она убирает экран,
  обработчики и возобновляет приостановленные модулем сцены. При уничтожении
  игры очистка происходит автоматически.

Каталог строится из `VN.data.storyMinigameLinks`: новые геймплейные сцены
появляются автоматически. Необязательные подписи кнопок находятся в `index.js`.
Индекс сюжетной сцены и `minigameId` совпадают с обычным игровым маршрутом.

## Саундтест

Кнопка «Саундтест» под игровыми сценами открывает экран с тремя ползунками
и кнопками для `test_music.mp3`, `ui_sound_test.mp3` и `test_voice.mp3`.
Первое нажатие запускает запись, повторное останавливает. Записи можно
слушать одновременно; после окончания кнопку можно нажать для повторного запуска.
Только в саундтесте громкость применяется и сохраняется при каждом изменении
ползунка. Используется общий `AudioManager`, поэтому значения действуют во всей игре.
«Назад» или Esc возвращает в режим разработчика. При выходе и открытии
режима разработчика тестовые звуки останавливаются. Переход в саундтест
не меняет сохранённую позицию сюжета.

Проверки жизненного цикла: `node --test src/developer/DeveloperMode.test.js`.
